雨晴代購 · 網站操作手冊

這本手冊帶您一步一步操作,放輕鬆跟著做就可以了 🌸

這個網站您主要會用到的,就是後台——也就是您管理訂單和商品的地方。
客人在前台逛、下單;您在後台看到訂單、準備出貨。以下每一段都是一件事,想到哪件就翻到哪段。

1進入後台

  1. 打開瀏覽器,連到您的網站(yuchingmakeup.com)。
  2. 點右上角的「登入」。
  3. 輸入您的管理員 Email 和密碼,按登入。
  4. 登入後,右上角會多一個「後台」——點進去就是您的管理中心。

網站最上方長這樣，「登入」在右上角（虛線圈起來的地方）。

後台首頁有好幾個方塊:訂單管理、商品管理、分類管理、網站設定…點進去就能操作。這本手冊接下來就是一個一個帶您。

進後台會看到這些方塊，點哪個就進去做那件事。

2處理訂單與出貨

客人下單後,訂單會出現在 後台 → 訂單管理。點任何一筆進去,就能看到買了什麼、客人選的取貨門市、電話。

訂單會經過這幾個階段,您按按鈕讓它前進:

  1. 待確認 → 您看過、確定要接單,按「確認訂單」。
  2. 已確認 → 您把商品用 7-11 賣貨便寄出後,按「標記已出貨」。
  3. 已出貨 → 客人到門市取貨、付款、完成後,按「完成訂單」。

上面深色的就是您要按的按鈕，每按一下，訂單就往右前進一格。

重要:實際的寄件是您自己做的。網站幫您記下客人要寄到哪家 7-11,但真正把貨寄出去,是您到 7-11「賣貨便」的賣家系統建立寄件、把貨交給店員。寄出後,再回網站按「標記已出貨」就好。

如果客人臨時不要了,或有狀況,同一頁也有「取消訂單」「標記棄單/拒收」等按鈕,按下去前都會再問一次,不怕手滑。

3匯出訂單清單

在 後台 → 訂單管理 右上角有「⬇ 匯出 CSV」。點一下會下載一個表格檔,裡面有所有訂單的收件人、電話、取貨門市、商品、金額。

這個檔可以用 Excel 打開,方便您一次整理要寄的貨、或留底對帳。

4新增商品

  1. 到 後台 → 商品管理,按右上角「＋ 新增商品」。
  2. 填商品名稱、選分類、填價格和庫存數量。
  3. 如果商品有不同款式(顏色、尺寸…),按「＋ 新增規格類型」,一種一種加進去,每種再填各自的價格和庫存。
  4. 下面可以寫商品介紹、上傳照片(可多張)。
  5. 按「建立商品」——商品就上架,客人馬上看得到。

5修改商品

在 後台 → 商品管理 找到商品,點右邊「編輯」。您可以改:

  • 價格、庫存:直接改數字存檔。
  • 上架狀態:想暫時不賣,把狀態改成「已下架」,前台就看不到了(但訂單紀錄還留著);想再賣,改回「上架中」。
  • 照片:可以新增,或勾選舊照片旁的「刪除」把它移除。
商品是用「下架」不是真的刪掉,這樣以前的訂單還查得到當時買的東西,對帳比較安心。

6一次匯入很多商品

要一次上架很多商品時,不用一個一個打。到 後台 → 商品管理 → 批次匯入:

  1. 先按「下載 Excel 範本」。
  2. 在 Excel 裡一列填一個商品(名稱、分類、售價、庫存…)。
  3. 回網站把填好的 Excel 上傳。若要一起放照片,把照片檔也一起選,系統會用檔名幫您對上。
  4. 按開始匯入,會告訴您成功幾筆、哪些需要修正。

7商品分類

在 後台 → 分類管理 可以:

  • 新增分類:填圖示(emoji)和名稱,按新增。
  • 改名或調順序:直接改欄位,按儲存。
  • 刪除:只有「沒有商品」的分類才能刪(避免不小心把有商品的分類刪掉)。

8商品圖片

您上傳的商品照片,系統會自動幫您存到雲端相簿,網站讀取更快,不用您操心。

如果哪天需要,後台 → 圖片雲端化 有一個「一鍵搬到雲端」的按鈕,平常用不到,放著就好。

9客人與售後

  • 客人取消訂單:客人可以在還沒出貨前自己取消,庫存會自動加回來。
  • 退換貨:客人在訂單裡送出申請後,您會在該訂單看到原因,再私下跟客人聯繫處理。
  • 客人名單與提醒:後台 → 客戶風險 會依每位客人的完成、取消、未取貨次數,幫您做個參考分數,方便您留意。
  • 暫停某位客人下單:在客人明細頁可以把對方設為「封鎖下單」,之後對方就無法結帳;想恢復按「正常」即可。

10網站設定

到 後台 → 網站設定,這些都能自己改,存檔後全站馬上更新:

  • 店名、標語
  • 最上方那條促銷文字
  • 運費、滿多少免運
  • 官方 LINE、聯絡 Email
  • 商品旁要不要顯示「已售 N」或「僅剩 N 件」

11新增管理員

想讓別人也能幫忙管理後台:

  1. 請對方先到網站的「註冊會員」註冊一個帳號。
  2. 您到 後台 → 管理員管理,輸入對方的 Email,按「設為管理員」。
同一頁也能取消別人的管理員權限。系統會保護「最後一位管理員」不被移除,不用擔心把自己鎖在外面。

12官方 LINE 客服

網站上「加入 LINE」「用 LINE 詢問此商品」這些按鈕,客人點一下就會直接開啟 LINE 找到您,不用自己搜尋。

客人針對某商品詢問時,訊息會自動帶上商品名稱,您一看就知道他問的是哪一件。平常就用您的官方 LINE 回覆客人即可。

13資料備份

訂單和客人的資料會定期自動備份,並存一份到雲端,您不用特別做什麼。

這部分是由架設網站的人在電腦上設定好的自動作業。您只要知道「資料有在自動備份、很安全」就可以了。

14啟動網站

正常情況下,網站在主機電腦上會「開機自動啟動」,您不用管。萬一需要自己手動啟動(例如發現網站沒開):

  1. 在網站的資料夾裡找到 啟動網站 這個檔,連點兩下。
  2. 會跳出一個黑色小視窗開始啟動——這個視窗請保持開著,關掉網站就會停。
  3. 等它顯示啟動完成,用瀏覽器打開 yuchingmakeup.com 就看得到網站了。
想更方便:對著「啟動網站」這個檔按滑鼠右鍵 → 傳送到 → 桌面(建立捷徑),桌面就會多一個捷徑,以後在桌面點兩下就能啟動,不用再進資料夾找。
遇到不確定的地方,先別急,大部分按鈕按下去前都會再問一次確認。
真的卡住,就把畫面拍下來、記下您想做什麼,請幫您架站的人協助。🌸
